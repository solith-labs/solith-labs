# Solith Labs

Autonomous crypto intelligence platform for real-time narrative and on-chain signal detection.

## Objective

Design and implement production-grade systems that combine heterogeneous data ingestion, lightweight autonomous agents, and calibrated signal generation to surface high-signal crypto events at the earliest possible stage.

## Technical Focus Areas

- Multi-modal data pipelines (social platforms + on-chain event streams)
- Agentic architectures for semantic understanding, narrative scoring, and meme detection
- Signal calibration frameworks with quantitative evaluation (precision, recall, lead time)
- Research into conviction markets and reputation-weighted verification primitives
- Simulation and backtesting environments for early-signal robustness

## Stack (Current / Planned)

- Python 3.11+ with async I/O and structured logging
- Lightweight LLM tool-calling agents (stateless, configurable)
- On-chain indexing via public RPC endpoints and subgraph APIs
- Event-driven alerting layer with configurable thresholds and deduplication
- Evaluation harnesses using precision, recall, lead-time, and false-positive rate

## Current Status

Early infrastructure and research phase. Primary focus is on data pipeline robustness and small-scale agent experiments. No production deployment yet.
